# Introducción al tutorial

:::info[EN PROCESO]

Toda esta documentación está en proceso, así que te pedimos paciencia ;)

:::

Te damos la bienvenida al tutorial de RCV - VSCode.

Aquí aprenderás todo sobre nuestra extensión, desde cómo usarla hasta las preguntas frecuentes.

<details>
  <summary>Tutorial integrado</summary>

Puedes ver un tutorial integrado, aunque no tan completo como este, directamente en VSCode.

Solo haz lo siguiente:

1. Abre la Paleta de comandos (`Ctrl + Shift + P`)
2. Busca el comando `*Open Walkthrough*`
3. Selecciona el tutorial `*Get started with RCV - VSCode*`

Cuando lo abras, verás algo como la siguiente imagen. Solo sigue las instrucciones de ahí para hacer una configuración rápida; recuerda que siempre puedes regresar aquí para más información :)

![Tutorial introductorio](./media/intro-walkthrough.png)

</details>
