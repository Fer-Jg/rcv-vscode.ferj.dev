# Requisitos

Conoce lo que necesitarás antes de usar **RCV - VSCode** en todo su potencial.

- Python 3.12 o superior
- Una extensión de VSCode que te permita previsualizar PDFs.
    - La extensión recomendada es [vscode-pdf by tomoki1207](https://marketplace.visualstudio.com/items?itemName=tomoki1207.pdf). Es una herramienta popular y sencilla para previsualizar PDFs.

:::warning

En la versión actual, [vscode-pdf by tomoki1207](https://marketplace.visualstudio.com/items?itemName=tomoki1207.pdf) es el único visor de PDF compatible. Puedes sugerir nuevos visores en nuestro Discord o GitHub.

:::

## Herramientas útiles

:::note

Lo siguiente no es **obligatorio** para usar RCV-VSCode, solo son conceptos de calidad de vida que vale la pena considerar para una mejor experiencia.

:::

### Formateador de archivos YAML

Para mejorar tu experiencia usando *RCV- VSCode*, recomendamos tener un formateador de archivos YAML con soporte de esquemas. Así podrás tener autocompletado para las funciones de RenderCV y un [linter](https://www.reddit.com/r/AskProgramming/comments/1iptihk/what_is_a_linter/) automático para corregir entradas en tiempo real*.

[YAML by Red Hat](https://marketplace.visualstudio.com/items?itemName=redhat.vscode-yaml) es la extensión recomendada para tener la experiencia completa.

:::note

***"corregir entradas"*** no incluye revisiones de gramática ni ortografía; la extensión solo revisa que las entradas sean válidas y que RenderCV pueda interpretarlas.

:::
