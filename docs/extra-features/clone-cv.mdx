# Clone CVs

Cloning a CV is just as simple as creating a CV:
1. Open the RCV-VSCode side bar
2. Right click the CV you want to clone (or click the 3 vertical dots on the right of any CV)
3. Select "Clone CV"
4. A new window comes up, similar to the CV creation window, inheriting the configurations from the cloned CV
5. Change whatever you want to change (or not, but at least use a new CV name)
6. Scroll down and click on the blue "Clone CV" button
