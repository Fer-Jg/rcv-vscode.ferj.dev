# Edit CVs

Editing a CV is really simple:

1. Click on the RCV-VSCode custom sidebar (paper icon)
2. Select the CV that you want to edit (which opens it directly)
3. Wait for the PDF to be generated and previewed
4. Edit your YAML file to your liking
5. Save your file and see your updated PDF (if you have on-save rendering enabled)

:::info

To see the actual PDF output file that you can upload anywhere, read [the next tutorial](./cv-output.mdx).

:::
